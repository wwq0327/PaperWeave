# 拾题成卷 PaperWeave

面向教师本人的本地题库桌面应用：从原卷 PDF 录题、拆题打标签、审核入库，到检索选题、组卷、生成学生卷与教师答案卷 PDF 并打印。覆盖小学至高中全学科，离线可用，题库与数据全部保存在本机。

## 状态

方案已定，M0 开发中（跨平台安装、编辑打印与 AI 输入验证）。当前进度见 [docs/HANDOFF.md](docs/HANDOFF.md)。

## 参与开发

开发按 Issue 驱动：每个可独立验收的功能或缺陷先建 Issue，分支名带 Issue 号，PR 关联 Issue 并逐条回填验收结果后关闭。流程细节见[协作方案](docs/GitHub协作与开源发布方案.md)。

真实题库、用户原卷与 AI 密钥不进仓库。自动化测试使用合成样卷、自制样本与固定模型响应，贡献者无需真实题库、付费账号或个人密钥即可运行测试。
