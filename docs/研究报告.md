# 小学至高中全学科题库软件研究报告

2026-11-04 · 第一轮研究结论

第二轮已下载并抽核小学和初中卷面，核读了题库源码。补证和修订见[原卷与题库对照研究](原卷与题库对照研究.md)。

**软件要同时容纳试卷题目和可评价的实践任务。** 用同一套身份、来源、版本、课程映射和检索结构管理它们。题目内部按材料、作答和评分拆开。这样，语文阅读和地理读图可以共用题组结构，听说、实验、体育和艺术仍能保留各自的执行和评分规则。

研究依次完成[方案编写与自审](研究方案.md)、课程范围梳理、原题抽样和项目对照。[样本与来源](样本与来源.md)有 23 张定位卡。初中文化科证据最齐，小学和高中一部分科目仍只有评析、政策或样例。以下字段是研究提案，已做文档层面的逐例检查，尚无软件实现或往返导出测试。

## 一、先把四个层次分开

| 层次 | 管什么 | 容易丢失的关系 |
|---|---|---|
| 来源与原件 | 命题或发布单位、原始载体、地区、年份、版本、出处、可用范围 | 同一卷的空白卷、答题卡、解析卷、听力稿与音频；一份卷里引用的文章、地图和照片各有自己的来源 |
| 试卷与题组 | 分部、指令、题号、分值、顺序、共用材料、选答、播放规则 | 江西政史合卷有两个科目分部。小学语文习作二选一只计一次分。英语听力顺序不能随意打乱 |
| 小题与作答 | 设问、需要展示的材料、一个或多个作答槽、限制、参考答案和评分 | 试卷的题号、可单独评分的小问、答题卡位置可能是三个不同编号 |
| 课程与评价 | 学段、适用年级、学科、课标目标、知识点、能力、难度依据、评分过程 | 同一题可映射多个目标或不同教材版本。题型、知识点、能力和难度各回答不同问题 |

试卷编排可用「卷 → 分部 → 题组 → 题或子题」。共用材料通过有序引用关联。独立题可直接挂在分部下。题的稳定编号与原卷题号分别保存，组新卷时产生新卷面号，保留原卷定位。原卷中一道题在不同试卷出现时，可分别保留收录记录和分值。定稿试卷锁定题目、材料和评分版本。卷首给出的统一常量、工具或书写要求也要有独立记录，拆题时判断是否必须随题带走。

## 二、可讨论的字段字典

字段名用来说明概念。暂不决定数据库、应用框架或文件格式。

| 对象 | 应记录的字段 | 何时允许缺失 |
|---|---|---|
| 来源 Source | 来源编号、来源类型、标题、来源机构或采集者、原始链接或文件、地区、日期、发布关系、使用范围、核验状态 | 机构、日期、权限未核时显式标记未知，附依据。保留“卷面所见”和“文件名推断” |
| 试卷 Paper | 稳定编号、版本、考试类型、科目分部、适用学段、考试时长、总分、卷面指令、题目顺序、选答规则、答案与答题卡引用 | 无整卷的单题保留来源定位，允许脱离试卷存在 |
| 题组 Group | 稳定编号、父级、共用指令、材料列表、子题顺序、组内约束、是否允许拆组、哪些小题依赖前问 | 独立题可没有题组。组内依赖不明时先按整组保留 |
| 材料 Stimulus | 稳定编号、版本、类型、正文或媒体引用、呈现顺序、原材料出处、来源页码及裁剪位置、题干或评分用途 | 音频缺失仍可保留题目和听力稿，标记交付不完整 |
| 题或任务 Item | 稳定编号、版本、设问、学段与适用年级、学科映射、任务类型、原卷定位、材料引用、作答槽、审核状态 | 采集阶段允许元数据不足。缺题干或关键材料的记录不进入可组卷池 |
| 作答槽 Response | 槽编号、输入类型、选项池或匹配集合、可选数量、顺序、数据类型、单位或格式、字数或时长、纸笔位置 | 槽按任务条件选填。一个小问可以有几个槽，也可以只提交一件作品 |
| 评分 Scoring | 评分方式、参考答案及出处、可接受变体、分值、部分得分、评分点或量规、档位、步骤与扣分、人工复核要求 | 原题尚无答案时标记缺失。解析可后补，出处和审核状态与参考答案分别记录 |
| 媒体 Asset | 原文件引用、版本或指纹、文件格式、角色、图表或公式语义、文本替代或等效材料、使用范围 | 原图有用时保留原图。文字替代可能泄露答案的情形标记需审核 |
| 课程映射 Alignment | 课程版本、学段、年级区间、学科、模块、知识点、能力或课标目标、主要或次要、判定依据 | 可仅到学科或年级。推断标签保留来源与待核状态 |
| 操作任务配置 | 场地、器材或软件环境、限时、操作步骤、交付物、观察点、安全限制、考评者和评分表版本 | 现场活动、实验、上机和作品题按需使用。一般笔试只需注明交付条件 |
| 难度与质量记录 | 人工估计的难度及依据、实测难度的样本和时间、内容审校、图文完整、权利状态、重复关系 | 无作答数据时可留空或标注估计。不要混入实测正确率 |

一个题目的参考答案可能正确而解析有误。原题、发布方答案、机构转录、教师校订、AI 草拟应保留各自身份和版本。同一题源重复出现时，先标同卷、转录或疑似同题，再决定是否合并。公开链接与使用范围独立保存，尤其是原卷中的文章、图表和音频。

## 三、题型按四个维度组合

1. **任务是什么。** 识别、计算、翻译、概括、举证、论证、实验探究、设计、表演等，可跨学科复用。
2. **给了什么材料。** 文字、音视频、地图、公式、表格、曲线、流程图、程序、装置、现场器材、现实情境可组合。
3. **交什么结果。** 单选、多选、判断、匹配、排序、短文本、数值、表达式、长文、图形、录音、程序、文件、现场表现或作品。
4. **如何判分。** 精确匹配、选项集合、允许等价答案、数值容差和单位、步骤给分、分析式量规、整体等级、现场观察、实测换算、程序测试与人工审核。

例如，地理读图可以用单选，也可以要求说明原因。物理实验题既可能是纸面读图填空，也可能在现场观察操作。语文阅读里的留言条可以归在原卷阅读分部，作答类型同时是情境写作。这样检索可以按学科、材料或能力分别找题。

## 四、用题目回推规则

| 样本 | 纸面推演 | 可验收结果 |
|---|---|---|
| S01 小学语文题15、17 | 题15共享三则材料，分别作答，组总分11。题17两项任务共享同一选答槽，选一，最多30分。 | 选一后整卷总分仍为100。原评分标准缺失时只复原卷面分值与要求。 |
| S03 江西初中数学题23 | 四小问共享几何情境，分别引用正式图和备用图。前两问结果和后两问论证分别记录。 | 任意选取小问前检查是否依赖前问或共用图。图序、数学符号及题目条件能回查原页。 |
| S04/S12 英语两种组题 | 听力组锁定播放、读题及作答窗口。七选五给五个空关联同一候选池。完形则给每空一组选项。 | 调换题序时空位仍对应选项，音频缺失时提示无法完整交付听力练习。 |
| S05/S06 理化题 | 物理题按装置图、数据表和多个作答部位拆解。化学方程式与装置选择可在同一小问设置不同槽。 | 参考答案分项能对齐原设问。化学式上下标和箭头条件保留。判等规则待学科审定。 |
| S08/S09/S10 史地生材料 | 历史保留每则材料的出处与小题引用。地理保留图号、图例和坐标，生物保留分类层级和坐标轴。 | 拆题时生成题干所需的完整材料集合。图文字替代必须兼顾可读性和答案暴露。 |
| S11/S17/S18 现场操作 | 现场实验用观察点评分，体育用单位明确的实测值换算，劳动用作品与过程量规。 | 能用不同年度规则重算体育成绩而不改原始测量。实验和劳动可单独保存观察过程与成品证据。 |
| S15 高中技术 | 信息技术把纸面算法阅读与实际代码运行分别标注。通用技术保留设计约束、草图和材料选择。 | 支持提交代码或草图，但评分细则在获得原始量规前保持待核。 |

## 六、软件需求可以先写到哪一步

- **资料入库**。原件留底，拆出卷、题组、材料、题和答案。逐项标明可供检索、可组卷、可判分、可对外使用的范围。按题库所需区分原卷、校订、改编和自编。
- **检索**。同时支持原卷视角和题目视角。学段、年级、学科、课标、材料、作答方式、任务能力、题源和审核状态可组合。跨学科题可挂多个学科与目标。
- **组卷与输出**。按蓝图分配题量、分值、材料和时长。自动提示缺图、缺音频、重复材料、组选题规则冲突以及分值不一致。至少分别考虑学生卷、答案卷和答题卡的内容关系。现场任务可输出操作说明与评分表，数字任务另附媒体和作答环境说明。
- **质量验收**。同一样本做三项检查。能按原卷找回题和材料，能重新编排且题意不变，能按已知评分规则对齐答案。原卷没有提供的答案、分值、许可或评分细则要可见地留空。

后续研究优先补小学非语文正式样本、高中六门选考的完整原卷与评分包、上机原始任务，以及艺术、劳动、综合实践的学校任务和量规。每类优先找一份同时具备任务、材料和评分依据的可审样本，再增加不同年份或地区做对照。阶段成果是能够判断字段设计的样本集。是否着手实现和选择软件底座，另行决定。


## 七、自审与核验记录

- 按研究方案逐项检查。课程目录覆盖了三个学段的国家课程类别，证据表按实际获得的材料标出原题、转录、评析、任务示例和缺口。
- 复查了扫描 PDF 的实际页面。江西物理答案文件的网页识别标题与卷面不同，以实际页面和政府附件目录为准。小学数学链接失败留档，暂不提取该卷字段。
- 修订了三个容易误判的地方。题组选答的候选分值不可直接累加。照片、示意图和图例可直接影响作答，导出时需要随题保留。考试院评析无法替代评分细则。
- 研究按结构差异抽样。每科不同地区、年级和年份的代表性，课标逐条映射和授权范围，仍需以正式入库批次验收。
