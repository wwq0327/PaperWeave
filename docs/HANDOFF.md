# 拾题成卷 · PaperWeave 项目交接

2026-11-04

## 已确定

- 目标是做覆盖小学、初中、普通高中全学科的题库软件。现阶段优先研究实际考试科目，按学段、地区、年份和考试类型区分。
- 已明确采用 Node.js，最终交付跨平台本地桌面应用，主流程为原卷录题、拆题打标签、检索选题、组卷打印。当前只定方案，开发待启动。
- 项目计划开源并同步 GitHub。按 Issue 提需求、用 PR 交实现和测试、逐条验收后关闭需求。必要且可公开的测试文档随代码提交，真实题库和 AI 密钥留在本机。[GitHub 协作与开源发布方案](GitHub协作与开源发布方案.md)
- [本地跨平台应用方案 V1](本地跨平台应用方案-V1.md)建议使用 Electron，首批验收 macOS 和 Windows。
- 首版 AI 从教师确认的文字或少量扫描裁图生成拆题和标签草稿，用户对照原卷审核后入库。首轮以用户熟悉的小学语文、小学数学、初中语文和初中数学做学科验收。

## 已做到哪一步

- 盘点了本地旧题库、原卷和软件原型，完成了第一轮网络与 GitHub 调研。当前样本清单有 25 张证据卡，包括原卷、公开转录、官方评析和评价任务示例。
- 初步判断是把一道题拆成材料、任务、作答与评分，并保留来源和版本。选答规则、共享材料、卷首条件可能属于题组或试卷，抽题时要检查这些依赖。
- 第二轮已下载 19 个公开 PDF，覆盖初中九门文化科、小学数学和英语。对照了本地小学语文、初中语文与数学卷，并核读学之思、BCTK 和 H5P 源码。高中部分选考原卷与分步评分仍待补。
- 旧库校勘发现 mathVault 2023 南充数学第 25 题的设问和条件有偏差，已记录为迁移前必核项。
