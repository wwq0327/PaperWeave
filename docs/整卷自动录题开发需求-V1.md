# 整卷自动录题开发需求 V1

2026-11-05 · 下一阶段主任务 · 修订 REQ-01、REQ-02 与相关验收口径

## 要解决的问题

教师导入一份原卷，系统自动拆题、切图、填字段并生成一批待审核题目。教师只需设置一次整卷参数，核对结果并批量确认入库。

现有流程要求教师先选文字或框裁图，再逐题采纳到当前表单。它保留为补录、修正和失败兜底入口。既有固定响应测试只证明流程可运行，不能作为整卷能力或真实识读质量的验收依据。

## 主流程

1. 选择原卷文件。首批支持 DOCX、带文字层的 PDF、扫描 PDF，混合 PDF 逐页识别。可选择同卷答案或评分文件。旧版 .doc 先提示另存为 DOCX。
2. 一次设置学段、学科、年级、考试类型、年份、来源与标签规则。整卷参数自动继承到各题，教师可批量修正或调整单题。选定模型服务和本次授权范围后启动整卷任务。
3. 系统提取文字、布局和图表，自动定位题号、小问、材料及跨页关系，再由 AI 输出结构化结果。程序按定位提取内嵌图或自动裁图。教师无需逐页选字、框图或逐题点发送。
4. 校验后直接批量创建待审核题目。结果页按原卷顺序显示，支持跳回原页或 DOCX 段落、查看题图和关联材料。异常集中列出，可修正、重跑或跳过。
5. 教师可批量确认通过项入正式题库，待核项保留在草稿。可筛选和多选，无须逐题打开编辑表单保存。正式题目继续遵循现有审核和版本规则。

## 开发约束

| 项目 | 要求 |
|---|---|
| 文件提取 | DOCX 保留段落顺序、表格、内嵌图和公式线索。文字 PDF 保留页码与定位，扫描页使用页面识读并保留坐标。公式或图表识读不可靠时保留原图和定位，标待核。 |
| 拆题与填字段 | 输出原题号、小问号、题干、选项、作答位置、题型、知识点、题图及表格、共享材料、原分值、答案和解析。整卷级字段由用户参数继承。缺少出处的答案、分值和解析标为待补，不自动编造。 |
| 切图与材料 | 裁图以可回查的原页坐标或文档对象为依据，处理跨页题、多图和共享材料。共享材料建一次并关联各题。答案按题号和小问号匹配，歧义标待核。 |
| 校验与重试 | 检查漏号、重号、页序、图表缺失、跨页断裂、答案错配与无效字段。整卷任务显示进度，可取消并重跑失败批次。相同来源重试不得重复建题或覆盖已审数据。 |
| 模型与数据 | 优先在本机提取和切分。使用外部模型前按整卷任务说明服务、拟发送的页或数据范围及费用条件，取得授权后由系统自动分批。模型超限、不可用或返回无效结果时保留可恢复草稿。 |
| 复用与对照 | 优先复用现有题库字段、材料关系、原卷定位、AI 响应校验、草稿审核和重复检查。用 Tiku、mathVault 的已校对结果及切题、图片提取规则作对照。针对单卷硬编码的题数和题型分段不得作为通用实现。 |

## 开发顺序

1. 先用一份已校对的 DOCX 和一份文字 PDF 打通原卷导入、自动拆题、结构化批量建档及整卷审核。
2. 接通扫描 PDF 的整卷识读、自动裁图、跨页拼接和图表回查，并处理同卷答案、共享材料和混合页。
3. 用真实模型和真实试卷做端到端验收，覆盖取消、失败重试和重复导入，再根据误差与人工耗时调整。

## 验收清单

- [ ] 分别用一份已校对的 DOCX、一份有文字层的 PDF、一份带图且含跨页题的扫描 PDF。每份从原文件开始，只设置一次整卷参数并启动一次，过程中无需手动逐题选字、框图、发送、填表或保存。
- [ ] 对照原卷逐项核验题数、题号与小问、题干与选项、跨页归属、共享材料、切图、答案对应、参数继承及来源定位。题号缺失、重复、错配、图文截断或字段不确定必须可见并可处理。验收样本的漏题、错切与答案错配均需处理后才计通过。
- [ ] 能从整卷审核页批量确认通过项。待核项不混入正式题库，重跑失败批次和重复导入不产生重复记录，不覆盖已审核版本。
- [ ] 真实模型调用经授权执行，留存模型、样本类型、自动处理耗时、人工核对耗时、每类修正项及最终结果。与同卷手工录题耗时对照。固定响应只用于自动化回归。
- [ ] 验收证据公开前脱敏。原卷、答案、题库、密钥和未授权模型输入留在本机。
