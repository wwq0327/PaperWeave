- **纸样**：未完成实体打印的纸面视觉确认；安装包内打印入口未人工验收。
- **Windows**：无硬件，安装、启动、Squirrel 安装器与打印均未实测。
- **升级**：没有更早的已发布版本，升级以「上一版构建 + v6 数据」模拟；真实覆盖安装未做。
- **跨机器恢复**：备份恢复仅在本机自动化验证，跨机器与跨平台未做。
- **学科复核**：四学科真实样题走查未执行；旧库真实数据（Tiku／mathVault）的学科抽核未执行。
