## 1. 要做成什么

一款用 Node.js 开发的跨平台本地桌面应用。教师打开 App，把手上的试卷分科录入，按原卷拆题、打标签、校对入库。备课时从题库挑题，组一份卷，打印给学生。题库是 App 的一部分，还要有录题工作台、组卷和打印、历史卷与备份恢复。

首版给教师本人使用。用户亲自做学科验收的范围是 **小学语文、小学数学、初中语文、初中数学**。题目模型能容纳其他学科，首版用少量其他学科样题检查结构能否通用，正式扩科时再安排学科校审。

**首版完整流程**：原卷 PDF → 人工录题或 AI 生成拆题、标签草稿 → 对照原卷审核 → 入库 → 筛选和选题 → 组卷并预览学生卷与教师答案卷 PDF → 定稿保存 → 打印。

## 2. 功能和验收

### REQ-01 原卷管理与录题工作台

- 可选本地 PDF，登记学段、学科、年级、地区、考试类型、学年和卷名。来源信息未知时可标待补，混合学科卷按分部标科目。原卷、答案、评分细则、答题卡分别挂接到同一场考试。
- 左边看原卷，右边编辑题。可以定位到页、缩放、提取已有文字或裁取题图。扫描卷可看图、手工录入。草稿允许跨次编辑，退出再打开能继续。
- 首版编辑器支持中文段落、常用强调与上下标、公式、图片和基础表格。无法支持的格式要提示，允许保留清晰裁图或手工改写并核对，不得静默丢字、丢图或改变题意。
- 保留原卷副本和文件指纹。重复导入同一文件时回到现有原件，可继续补录。文件重复与题目重复分别判断。录题时若同一卷、同一分部已有同号题或小问，提示查看已有条目，教师可选择继续编辑或明确建立修订版。

**验收**。导入一份未入库的 PDF，录一道带图题，退出后重新打开，从题目跳回对应原页。再导入同一 PDF，原件记录只有一条。另从编辑器输入中文、修改公式、插图和基础表格，保存重开并导出，内容与编辑结果一致。

### REQ-02 AI 辅助拆题和打标签

- 在录题页选一段可提取的 PDF 文字、粘贴转录文字，或从扫描卷选取一题或一组题所需的少量裁图。跨页题可选择多个有序区域。AI 建议题组、小问、设问、选项、作答位置、共享材料关系和候选标签。优先使用本科目的已有标签，新增标签由教师确认。草稿关联本次选区的原卷页，识别不清的字、公式、图和依赖标为待核。
- 首版以小批次辅助拆题为限。模型返回的内容进入待核区，逐题允许修改、采纳或跳过。选区缺前页、图形无法辨认或模型缺图像能力时，提示补选、换用已配置的图像模型或手工补录。答案和评分以教师核过的材料为准，缺来源时保持待补。正式入库须由教师确认。
- 人工录题、浏览、组卷、打印和备份可断网完成。AI 调用前展示模型服务、输入方式和拟处理的文字或裁图，由教师确认。云端调用只处理确认的内容，原卷整份文件、题库和其他资料留在本机。模型连接失败、取消或输出无法解析时，保留人工草稿并允许手录或重试。迟到或重复的响应不能覆盖人工编辑，也不能生成重复的正式题目。
- M0 确定并记录单次文字量、裁图数量与大小、超时等使用上限，提交前提示超限及拆分办法。AI 是否省力按选区、等待、校对和采纳的总耗时与人工录题比较，测试结果不预设为有效。

**验收**。用本地南充九年级语文卷的文字、公开东城小学数学卷的一道带图题裁图，各生成一份草稿，核对后采纳。另测取消后返回、异常格式和重复提交，确认人工修改仍在，正式题库只收教师确认的题。自动化用固定响应，两种输入分别保留真实模型调用与人工核对记录。

### REQ-03 题目结构和审核

- 原卷位置由科目分部、PDF 页、原题号及小问号组成。题库内部另用稳定编号，组卷后生成新题号。材料、题组、小问、作答位置、参考答案、评分点各自记录，能表达多份共享材料、一问多个空、前问依赖、组选答和同一作品的多个评分点。
- 文字、公式、图片、表格进入对应题干、选项、材料或答案。原卷图和解析图要区分。保留原分值和已取得的评分依据，题目解析单独存。识别出来的题干允许校订，留存来源和原编号。
- 审核时检查题意、材料、题号、标签、答案和分值。**内容审核状态**分草稿、待核、已审核，**答案和评分资料状态**单独记录。已审核题的设问、材料、作答要求、答案或评分发生实质修改时，新版本回到待核。已经定稿的试卷可重印原版本。
- 审核结果绑定题目及其引用的材料、前问、答案和评分版本。共享材料或前问修改时生成新版本，列出直接和间接受影响的题目；采用新版本的题回到待核。已审核版本和组卷草稿不自动切换到新版，草稿提示可更新并由教师选择。定稿固定原版本。
- 题意和材料完整并已审核的题才能出卷。答案或分步评分待补时，允许教师确认后出卷，教师版在相应题处提示。题意不完整、必要材料缺失或依赖未解决时阻止定稿，并指出哪道题缺什么。

**验收**。能记录小学语文二选一习作与留言条分项评分，以及初中数学需要前问条件的综合题。题干和材料缺失时触发阻断，只有评分资料缺失时能提示并由教师决定。一份材料被三道题引用，修改后能列出受影响题；采用新版的题重新审核，原组卷草稿不被静默替换，旧定稿不变。

### REQ-04 题库检索与选题

- 支持按学段、学科、年级、知识点、题型、年份、来源、审核状态组合筛选和按题干关键词搜索。题目可挂多个知识点，年级或知识点有冲突时可修改后再入库。
- 结果能预览题干、来源和材料，教师能查看答案。点中小问时提示是独立可用、需要共享材料、需要前问，还是需要整组。入篮前列出直接和间接依赖，由教师确认追加后入篮。同一处的共享材料打印一次。去掉前问或移动小问后重新检查依赖和顺序。
- 依赖包括题组指令、卷首共用条件和选答规则。首版默认带齐适用前提；无法独立抽取时带入整组。若教师要删改前提、把前问条件改写进题干或改变选答规则，须建立题目或题组修订版，重新审核后再用。
- 题干、材料和答案中的题号、图号、材料号引用与对象关联，重排后显示对应的卷内编号。无法可靠转换的文字或图片内引用列为待核，保留原意并经教师确认后才能定稿；不能仅靠替换数字处理引用。教师的确认只对当前内容和编排有效，相关内容或编号再变时重新核对。

**验收**。用两项以上筛选条件找到同一科的目标题。重复加入同一题会提示；抽到依赖前问的小问时，能看见需要补入的内容。把原第（3）（4）问排为第（1）（2）问，题干和答案内引用对应正确；缺必要条件或仍有未核引用时阻止定稿。

### REQ-05 组卷、定稿与打印

- 可在题篮增减题目、分大题、调顺序、设卷内分值和答题留白，显示总分。首版一份自组卷只选一科，小问的原分值保留。缺少卷内分值时由教师补填。首版选答按同分候选计分，例如二选一每个候选均为 30 分，组总分为 30 分。遇候选分值不同或规则无法表达，提示调整卷内分值或改用可表达的题组后再定稿。
- 卷内改分后，原评分细则标为“不适用于当前分值，待调整”，不自动按比例换算。教师可在本卷调整并确认评分，或确认仅输出参考答案、注明本卷评分待补。原评分依据仍可回查，不作为本卷正式评分打印。题干、图片和解析中内嵌的旧分值也要检查，未解决的冲突阻止定稿。卷内改分与评分调整只作用于本卷，不覆盖题库原分值和原评分。
- 用同一次定稿生成 **A4 学生卷和教师答案卷 PDF**。题序、编号、分值一致。学生卷只含作答所需的内容，教师版含答案和可用的评分点。预览和打印能辨认中文、公式、图表和选项，长材料可跨页，避免图被截断或题号与正文分离。
- 定稿前预览本次生成的两份 PDF，确认后保存为定稿，打印和重印使用这两份文件。编排或内容变化后重新生成并预览。A4 页边距和缩放规则在 M0 固定；图表超出可打印范围时提示调整，不能通过裁切或缩小到不可辨认来通过验收。
- 定稿固定题目、材料、答案、卷内分值和版式。两份 PDF 都成功写入且能打开后才记为定稿。任何一份生成失败时保留组卷草稿和此前的定稿。同一次提交的重试只产生一套有效定稿。重印优先打开原定稿的 PDF。
- 保存题目、附件或定稿时中断，重开后应恢复到完整提交的状态或可重试的草稿，不能把缺文件的记录显示为已完成。此前保存的题目和定稿仍可用。

**验收**。分别组一份语文卷和一份数学卷，核对共享材料、题序、总分、答案对应和留白。将一道 6 分题改为 4 分，学生卷无冲突旧分值，教师卷不把原 6 分细则作为本卷评分。实际打印样页，与最终 PDF 核对。修改原题后重印旧卷，内容与原定稿一致。分别在写附件、生成第二份 PDF、提交定稿时中断，重开后检查无缺件的正式记录，旧数据仍可用。

### REQ-06 旧题库迁入与数据恢复

- 首批迁入 Tiku、mathVault 各一组题。先看可导入、重复、缺图、失链、待校勘清单，再确认入库。保留原编号和材料引用。重复导入保持条数一致，未通过校验的条目有原因和修正入口。
- 迁入条目默认待核，旧库“已入库”等状态仅作来源记录，不能直接转换为“已审核”。同一来源编号且来源内容未变时跳过；来源内容变化时展示与当前记录的差异，教师选择建立修订版或保留当前记录。目标题已人工修改也不能被再次迁入静默覆盖；保留导入批次和处理决定。
- 备份包含一致的数据库副本、原卷、配图、定稿 PDF 和版本信息。恢复时先检查完整性，再切换到恢复出来的题库。恢复失败时可继续使用现有题库，备份中不存模型密钥。首次建库记录数据版本，后续升级需要迁移时用上一版备份验证可恢复。
- 备份附文件清单、校验值和数据格式版本。首版备份期间暂停写入并提示，完成或失败后恢复编辑。恢复在独立位置校验，切换完成并重开验证前保留原库；校验失败、版本不支持或恢复中断时，不覆盖原库。

**验收**。迁入一组多材料阅读题和一组带公式、图的数学题，分别测试完全重复、来源修正、目标题已人工修改，检查不重复、不静默覆盖。用南充中考数学第 25 题验证旧“已入库”状态仍进入待核，校勘后才能出卷。在两平台分别做一次备份与恢复，至少完成一次跨平台恢复，验证能打开原卷、题图和历史卷。另测备份期间编辑、缺附件、校验值不符、版本不支持和恢复切换中断，失败后原题库仍能打开。[旧题库盘点](本地题库资料盘点.md) · [校勘记录](原卷与题库对照研究.md)

### REQ-07 跨平台和本地运行

- 用 Node.js 实现桌面应用，提供可从图标打开的安装版。macOS Apple Silicon 和 Windows x64 是本版建议的验收配置。数据和文件使用平台无关的标识和相对路径，兼容中文文件名。
- 干净环境安装后能启动，日常功能可断网，支持系统打印和 PDF 导出。数据库、公式、字体和界面资源随应用安装或在本机读写。教师无需安装开发工具。具体技术路线见[本地跨平台应用方案](本地跨平台应用方案-V1.md)。
- 导入或粘贴的内容不能自动加载远程图片、执行脚本或读取无关本地文件。需要取得远程资源时先展示来源并由教师确认。模型密钥不进入题目、备份和日志。

**验收**。在两平台实际安装、断网打开、录题、筛题、导出和重开检查数据。两平台检查系统打印入口，至少在可用的实体打印机上实打并留样。缺少某个平台的实测时，该平台保持待验收。

## 3. 首版范围与待决定项

- **确定**。本地桌面、Node.js、跨平台。首版 AI 做拆题和标签草稿，教师对照原卷审核。首版输出学生卷和教师答案卷，后续扩充题源。
- **当前采用的建议**。先做 macOS Apple Silicon、Windows x64。首轮用用户熟悉的四个学科范围做教师验收。纸型先做 A4，首版一卷一科。AI 支持教师选中的文字或少量裁图，人工录题始终可用。
- **本次采用的规则**。抽取依赖小问默认带齐适用前提或整组，改编须重新审核。改分后不自动换算评分细则，可调整本卷评分或明确标待补。共享内容按版本引用，迁入默认待核，已有题目和定稿不被静默覆盖。
- **分阶段决定**。模型服务、费用及使用方式在 M0 先确认可行路径，实际调用按当次授权执行。开发初期用固定响应测试。Linux、其他处理器架构、Word 导出、整卷 OCR 和自动拆题、自动组卷、自动判分留到后续范围评审。
- **使用规模**。M0 根据现有题库和测试机器记录首版题量、原卷页数与文件大小、单卷题数、AI 输入上限，以及启动、检索、保存、导出和备份的耗时目标；据此验收，不把少量样题通过视为日用性能已通过。目标值和实测值分开记录。
- **交给开发 agent 的依据**。产品行为和验收以本文为准，技术路线看[本地跨平台应用方案](本地跨平台应用方案-V1.md)，执行和测试按[开发与验收流程](开发与验收流程-V1.md)。旧调研负责提供题源和案例。
