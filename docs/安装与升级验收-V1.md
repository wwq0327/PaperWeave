## 3. 升级行为（程序检查通过，真实旧版本人工升级未执行）

首次从 1.0.0 开始使用，本机没有更早的已发布版本。升级路径以上一节用上一版构建模拟的自动化结果为准，**尚无「真实旧版本安装 → 覆盖安装新版本」的人工记录**。迁移规则：

- 迁移前若数据库版本已低于当前版本，主进程先用 `VACUUM INTO` 在 `<userData>/.migration-backups/` 生成完整快照，再在单个事务内迁移。
- 成功：数据升到版本 7；快照保留，可手动取回。
- 失败：整次回滚，原库保持旧版本；应用显示「题库打开失败 / 原数据未被替换」并给出快照路径后退出，不会带着半迁移库进入界面。
- 升级不覆盖或删除原卷、配图与历史定稿文件；升级后的备份仍包含这些文件。

待有真实旧版本安装包后，须补一次人工覆盖安装（步骤同下节，安装前保留一套旧数据与备份）。

## 4. macOS 人工验收步骤（待用户确认）

准备：建议先备份现有数据（「备份与恢复 → 选择备份目录 → 创建备份」），并记下数据目录位置。全程可断网。

1. **安装**：双击 `out/make/dmg/arm64/PaperWeave-1.0.0-arm64.dmg`，把「拾题成卷 PaperWeave」拖入 `/Applications`，推出磁盘映像。若系统拦截，右键应用选「打开」再确认。
2. **断网启动**：关闭 Wi-Fi／拔出网线后，从「应用程序」启动。首屏应进入「编辑草稿」，不出现网络错误或空白窗口。
3. **完整流程**（用自制或已授权的原卷 PDF，勿用未授权的真实题库）：
   - 「考试原卷」导入 PDF，进入录题；在左栏拖选裁图、填写题干／答案／评分，提交待核。
   - 「题目审核」核对公式与题图，通过内容与答案。
   - 「题库与组卷」检索该题，加入题篮，建卷并加入小节，检查定稿通过后点「生成学生卷与教师答案卷」。
   - 两份 PDF 应自动交给系统默认程序打开；学生卷无答案，教师卷末尾有参考答案。
4. **打印入口**：在预览／PDF 程序中打开打印对话框，确认纸张 A4、缩放 100%；实际打印学生卷与教师卷各至少一页，检查边距、公式、表格、题号与分页。可直接使用 agent 已生成的自制合成样张：`out/终验样卷/一页双卷样张/`（1 页双卷，含公式与裁图）与 `out/终验样卷/50题双卷样张/`（学生卷 17 页、教师卷 50 页），说明见 `out/终验样卷/说明.md`；不进入仓库。纸样结论记入下方确认表。
5. **重开**：完全退出应用再启动，确认题目、原卷、配图、定稿、草稿与模型设置仍在。
6. **安装包内 AI**（可选，需当次授权）：在录题页「模型服务与密钥设置」填写服务地址、模型与密钥，用一份可上传的样本走文字或裁图拆题；确认草稿可校对、采纳后可修改、密钥不回显。真实调用会产生费用并上传所选内容，执行前须由用户确认服务、模型、费用上限与上传范围。
7. **备份与恢复**（可选，同批确认）：创建备份后修改一道题，再恢复该备份并重启，确认回到备份时状态；损坏备份应被拒绝且原库可用。
