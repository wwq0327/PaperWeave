# 一道题需要保存什么

2026-11-04 · 研究笔记，基于[既有卷面与任务样本](样本与来源.md)和[原卷与题库对照研究](原卷与题库对照研究.md)

一道题至少要能回答三个问题。**学生看到什么、需要交什么、教师依据什么判断完成得怎样。** 题库还需要回答第四个问题：这些信息从哪里来，改过什么。只有先分清这四件事，才能判断一道题能不能从原卷里拿出来用。

## 1. 字段归属

| 要素 | 放在哪一层 | 何时必须明确 |
|---|---|---|
| 设问与要求 | 题或小问。包括判断对象、任务、限制和指定表达方式 | 学生作答前必须可见。阅读材料内的关键词、图号等要能定位 |
| 材料 | 可独立引用。包括文章、图表、声音、公式、程序和器材说明 | 作答依赖它时必须随题带出。图片区分题干图、选项图和答案图 |
| 作答位置与方式 | 每个空位、选择或提交物各有标识。保留数量、顺序、单位、字数或时间限制 | 需要明确学生到底交几个结果，各结果怎么对应原题 |
| 参考答案 | 关联到作答位置，注明来源、版本与可接受变体 | 纯浏览可缺。标为可判分时必须具备对应判定依据。多个空可仅指定部分互换顺序 |
| 评分办法 | 评分点可读同一个作答位置，也可联合多个作答位置。保留分值、步骤、档位、默认分值及例外、合并或扣分规则 | 有总分并不代表知道怎样给分。原评分办法未获得时保留缺口 |
| 解析 | 解释答案、给出推导或示例，另记出处和审核状态 | 教学讲解可用。范文、示例解法和正式评分依据分别保存 |
| 来源与版本 | 题目身份、原卷题号、页码、转录或修改记录。材料可有自己的出处 | 正式入库时应可回查。原卷号随试卷而变，题目身份保持稳定 |
| 学科与教学标注 | 学段、年级、学科、课标目标、知识点、能力、任务类型、难度及其依据 | 检索需要，采集时可逐步补齐。人工估计和实测难度分别记录 |
| 共用条件 | 题组或试卷。包括选答、材料顺序、播放次数、统一常量、作答时间 | 从原卷抽题时检查是否继承。删掉后若题意或评分会变，就随题保存 |

## 2. 用四类题看分界

| 既有样本 | 题目要素如何拆 | 什么情况下不能直接抽题 |
|---|---|---|
| 小学语文二选一习作，S01 题17 | 两项写作任务分别保留题干。组选答规则规定交一篇，组满分30。 | 组卷若把两项都作为必答题，题量和总分都会变。没有评分细则时只确认卷面要求和总分 |
| 江西初中化学，S06 题18 | 装置图供多个小问使用。同一小问可同时有方程式和装置选择两个作答位置 | 抽出小问若失去装置图、编号或前面的条件，原设问便不完整 |
| 高中英语七选五，S12 阅读第二节 | 一篇文章、五个空位、一套共享选项。每空可单独记分，整组保留候选项和位置关系 | 只有一个空的文字、缺少全文或共享选项时，无法还原原任务 |
| 劳动剪纸评价，S18 | 存任务说明、工具、时限、设计说明和作品要求。量规分别观察过程与成品 | 只留作品照片，会丢掉工具使用、整理与劳动过程等观察证据 |

## 3. 判断一条记录能用到哪一步

1. **能查阅**。题干和来源可回查，缺失项可见。
2. **能抽题或组卷**。依赖的材料、卷首条件、前问和选答规则齐备。若只能整组使用，明确标记。
3. **能判分**。每个要评分的结果都有对应规则。人工评分与可自动判断的作答槽分别标注。
4. **能讲解**。解析可独立核查，引用的图文与参考答案版本对得上。

这四种状态分别记录。比如一份听力卷面能查阅，有听力稿仍可能缺实际播放音频。完整原题没有官方评分细则时，可以做原卷结构研究，评分部分需要继续查证。
