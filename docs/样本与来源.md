# 样本、来源与覆盖矩阵

2026-11-04。A 为核读原题或原始发布卷的指定部分，A− 为本地原件或公开转录、发布链或完整性待核，B 为可定位题号的官方评析、考试任务或评分规则，C 为课程或政策层依据。不同列可以同时成立。B 不补写缺失的原题或评分细则。PDF 页为文件页，特别标注的除外。

## 1. 课程覆盖

按普通小学、初中、普通高中梳理国家课程。外语保留语种维度，义教地方和校本课程保留挂接入口，高中保留必修、选择性必修与选修模块。地区的中考计分科目、合格考科目和高考选考科目另建目录。用这些基线建立索引，正式按特定年份和地区组卷时再核当年适用方案。[教育部义教课程方案](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582343217634.pdf) · [教育部普通高中课程方案与课标通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html) · [湖北实施办法与科目说明](https://jyt.hubei.gov.cn/zfxxgk/zc_GK2020/gfxwj_GK2020/202309/t20230908_4831408.shtml)

| 学段 | 科目或课程 | 本轮证据和缺口 |
|---|---|---|
| 小学 | 语文 | A− S01。高年级卷及本地卷面研究。低中年级样本未闭合。 |
| 小学 | 数学、外语、科学 | 英语与科学见 S20–S21 的公开扫描或转录。小学数学已补东城公开扫描、答案版和另一期评价标准，见 S24–S25。发布链与完整评分材料按各卷记录。 |
| 小学 | 道德与法治、信息科技、体育与健康、艺术、劳动、综合实践活动 | C 课程依据。体育、劳动、艺术有评价规则或任务示例 S17–S19，其他课程的任务包和评分材料待补。 |
| 初中 | 语文、数学、外语、道德与法治、历史、地理、物理、化学、生物学 | S02–S10 覆盖九科。第二轮已从政府渠道下载九科卷面及参考答案，见 [PDF 清单](../research/PDF清单.md)。外语实际播放音频、独立答题卡和完整评分包待补。 |

| 高中 | 语文、数学、外语 | S12–S13，语数以公开转录或评析作结构证据，外语有公开转录但听力原件缺失。其他语种未核卷面。 |
| 高中 | 思想政治、历史、地理、物理、化学、生物学 | S14 有省考试院按题号评析，历史与物理另见 S22–S23 转录或扫描。官方完整原卷与评分包仍待补，不能据评析确定每题分值与评分规则。 |
| 高中 | 信息技术、通用技术、体育与健康、艺术或音乐美术、劳动、综合实践活动 | S15 有技术科目题号和命题说明，S17–S19 可对照实践类记录模型。高中实际操作任务、艺术作品评价和综合实践档案样本待补。 |

小学质量监测、校内评价、期末练习、升学考试应使用不同来源类型。上海初中有开卷上机与理化实验操作，艺术和劳动技术可由学校综合评定。北京的初中外语听说、物理实验和体育过程成绩也是独立组成部分。地区做法应分别保存。[国家义务教育质量监测方案](https://www.moe.gov.cn/srcsite/A11/moe_1789/202109/t20210926_567095.html) · [上海初中学考实施办法](https://edu.sh.gov.cn/xxgk2_zdgz_rxgkyzs/20230412/ec0b8612c5c14970ad0260593696af43.html) · [北京初中学考问答](https://www.bjeea.cn/html/zkzz/faq/2025/0609/87134.html)
