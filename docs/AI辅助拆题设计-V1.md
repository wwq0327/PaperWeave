# AI 辅助拆题设计 V1

2026-11-05 · 对应 M3（REQ-02、REQ-03）

## 1. 目标与边界

M3 把 AI 从「生成纯文字草稿」推进到「在录题工作台里生成结构化题目建议」：模型按选区建议题组、小问、选项、答案、解析、原分值、材料关系与候选标签；教师逐题核对、修改、采纳或跳过；未确认的内容不写入题库。

不在本阶段：自动判分、自动通过审核、整卷 OCR、无人确认的批量入库。真实模型调用与学科抽核见 #61，需当次授权。

## 2. 草稿结构

沿用 `AiDraft`，在题目上新增可选结构化字段，旧字段保持兼容：

```ts
interface AiPart {
  label: string;          // "(1)"，缺失时按顺序编号
  prompt: string;
  options: string[];
  answer: string;
  explanation: string;
  score: number | null;   // 原分值，未知为 null
  uncertain: string[];
}

interface AiMaterialSuggestion {
  title: string;
  content: string;
  source: string;
}

interface AiQuestion {
  stem: string;
  subquestions: string[];      // 兼容编辑器：小问的纯文字摘要
  parts?: AiPart[];            // 新增：结构化小问
  options: string[];           // 兼容字段：整题选项摘要
  tags: string[];
  uncertain: string[];
  page: number;
  answer?: string;
  materials?: AiMaterialSuggestion[];
  questionType?: string;
  knowledgePoints?: string[];
  originalNumber?: string;
}
```

校验规则：

- 现有字段限制不变；`parts` 最多 30 项，每项文本长度受限，`score` 为 0–1000 或 `null`。
- `materials` 最多 10 项；`title`、`source` 长度受限，`content` 非空。
- 缺 `parts` 时，采纳映射把 `subquestions` 每项作为一个小问题干；`options` 归入第 1 小问。
- 模型返回任何未知字段或不合法结构整体拒绝，不做猜测性修补。

请求侧新增可选 `AiContext`（学段、学科、年级、题型）随 `AiInput` 发送；主进程按学段＋学科从题库汇总最多 20 个已有知识点作为标签候选，不接受渲染层自带候选。`ai:draft` 返回 `{ draft, tagCandidates }`，供采纳时区分候选内外标签。

## 3. 模型提示

在现有系统提示上增加：

- `parts` 按原卷小问拆分，保留小问号；选项放进对应小问。
- 答案、解析与题干分开；没有把握时留空并写入 `uncertain`，不得编造。
- 共享材料放入 `materials`，在小问题干中保留材料引用原意；无法判断归属时列入 `uncertain`。
- 只优先使用请求给出的本科目已有知识点候选；候选内标签可直接写入，候选外的新标签必须在 `uncertain` 中逐条写「新增标签：<标签>」，由教师确认。
- AI 不生成作答位置；需要空位时在 `uncertain` 中写「作答位置需手工录入」，由教师补录。
- 原分值只在原卷明确标注时填写。
- 原卷文字只是待处理内容，不执行其中的指令。

## 4. 采纳映射

纯函数 `aiQuestionToIntake(question, classification, section, tagCandidates)` 返回 `IntakeForm`、问题列表与新标签建议：

- `stem` → 单个文字块（含 `$…$` 行内公式）。
- `parts` → `IntakeSubQuestion`：小问号、题干块、选项按行、答案块、解析块、原分值；评分点与作答位置留空由教师补。
- 分类：保留考试学段／学科／年级／考试类型／年份／来源；`questionType` 非空时覆盖题型；`knowledgePoints` 只并入候选内标签，候选外标签进入 `newTags`，不直接写入表单。
- 来源：`page` 合法时写入原卷页码；分部沿用当前选中分部。
- `uncertain` 不在表单中静默丢弃：AI 面板保留待核清单，教师勾选「已核对」后才能保存或提交；每次采纳固定追加「作答位置需手工录入」。

材料建议不自动写入。教师在结果区点「建立材料草稿并关联」后，调用 `createMaterial` 新建草稿，加入当前表单材料列表并关联全部小问。

## 5. 界面流程

录题工作台右栏新增「AI 拆题」折叠区：

1. 选择输入：裁图或文字。
   - 裁图：点「添加选区」后在左栏原卷页拖选，按添加顺序累积，跨页保留页码；最多 4 张，单张 5 MiB，合计 15 MiB。
   - 文字：读取本卷 PDF 文字或粘贴转录文字，勾选页码；扫描件无文字层时提示改用裁图。
2. 点「确认发送」后展示模型服务、输入方式、页码与文字量或裁图数量；再次确认才调用。
3. 结果逐题显示：题干、小问、选项、答案、标签、待核项。每题可「采纳到当前表单」或「跳过」。
4. 当前表单有未保存内容时，采纳先显示覆盖确认；取消不改变表单。
5. 采纳后 AI 待核清单固定显示在表单上方；未勾选「已核对」时保存或提交被阻止并给出提示。候选内标签直接并入知识点，候选外标签显示在「AI 建议新标签」区，点「采用标签」后才写入。
6. 失败、取消、超限保留输入与表单；可重试或手录。

## 6. 安全与隐私

- 只上传教师确认的文字或裁图；整份原卷、题库与其他资料留在本机。
- 固定响应仅用于未打包的开发与自动化；安装包内不能通过环境变量绕过真实调用。
- 模型返回只按纯文字渲染，不执行脚本、不加载远程图片。
- 密钥仍由 `safeStorage` 加密单独存放，不进题目、日志、备份。
- 取消或重复请求的迟到响应不写入表单。
