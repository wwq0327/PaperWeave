# 拾题成卷 双卷生成设计 V1

2026-11-04 · M0 草稿级双卷样张设计，待实测与纸样复核

**目标：学生卷与教师答案卷分别由各自允许的内容字段生成，不靠隐藏答案元素；两份 PDF 同一次操作生成、校验后原子呈现。** 本期只覆盖当前 M0 单份草稿，不涉及按题号关联答案、评分结构或整卷编排。

## 1. 数据字段

当前草稿结构 `Draft`（版本 2）：

| 字段 | 学生卷 | 教师卷 | 说明 |
|---|---|---|---|
| `blocks`（段落/公式/图片/表格） | 渲染 | 渲染 | 题目内容，两份共用同一布局与编号 |
| `teacherAnswer`（纯文本） | **不渲染** | 渲染为「参考答案」节 | 仅教师卷允许的内容字段，学生卷 DOM 中不存在该节点 |

答案与题号的对应、公式/图片答案、评分点属后续数据结构，本期不实现，答案统一追加在教师卷末尾。

## 2. 生成流程

1. 教师点击「生成学生卷与教师答案卷」。
2. 主进程弹出目录选择；取消则结束，不产生任何文件。
3. 渲染层切到学生模式（只渲染 `blocks`），等待字体、公式、图片完成渲染并做 A4 越界检查后，主进程 `printToPDF` 取学生卷字节。
4. 渲染层切到教师模式（`blocks` + 参考答案节），重复等待与检查，主进程取教师卷字节。
5. 两份字节交给 `pdf-pair`：同目录暂存 → 校验 PDF 头尾与回读字节 → 目录重命名一次呈现；同一操作标识、相同内容重试返回同一目录，不同内容拒绝。
6. 打开两份 PDF；返回目录与打开错误。任一步失败不产生完整目录，界面保留草稿。

## 3. 内容隔离保证

- 纯函数 `volumeSections(draft, volume)` 决定每个卷可见的字段：`student` → `{ blocks, answer: null }`；`teacher` → `{ blocks, answer: teacherAnswer.trim() || null }`。
- 学生卷渲染路径拿到的 `answer` 恒为 `null`，因此答案文本不会进入学生卷 DOM；不是用 CSS 隐藏。
- 单元测试断言学生卷不含 `teacherAnswer`、教师卷包含；E2E 断言一次操作生成两份不同大小的 PDF。

## 4. 中断恢复

双卷操作在数据库 `app_settings` 的 `pdf.pending` 键记录进行中的操作（`{id, parent}` 列表），并随操作建立/清除：

| 崩溃时状态 | 启动恢复动作 |
|---|---|
| 已选目录、未生成任何文件 | 无文件可清，移除记录 |
| 写入暂存目录中或写完后未重命名 | 暂存目录名与记录 id 对应且只含「学生卷.pdf」「教师答案卷.pdf」时，删除暂存目录并移除记录 |
| 目录重命名已完成、记录未清除 | 保留已完成的定稿目录，仅移除记录 |
| 暂存目录含非预期文件 | **不删除**，保留记录并提示路径，交人工处理 |

恢复只删除 `parent/.paperweave-<id>.pending` 且内容符合预期的目录；已完成目录 `拾题成卷-样张-<id>` 一律保留。

## 5. 已知限制（不关闭 Issue #5）

- 无按题号/评分关联，教师卷答案只是末尾附加节。
- 中断恢复只清理文件级暂存；草稿本身由数据库保存，恢复后可重新生成。
- 纸样、安装包内导出、Windows 均未验；当前产物是样张，不是正式定稿。
- 系统打印仍从预览打开的实际 PDF 发起，打印时选 A4 与 100% 缩放。

## 6. 对应规则

- 方案 §3.2：学生卷与教师卷分别由允许的内容字段生成；PDF 生成前等待字体、公式、图片完成渲染。
- 流程 ACC-10：核对 A4、边距、公式、表格与图，学生卷无答案；预览后改编排必须重新生成。
