# 小学至高中全学科题库软件研究方案

2026-11-04 · 自审修订版

目标是回答全学科题库软件如何保存真实试题并支持检索、复用与组卷。范围包括小学、初中、高中，覆盖文化科、艺术、体育、劳动、综合实践、信息科技与高中技术类课程。外语以英语样本先验证，其他语种列待补证。只开展资料研究并写文档。

## 研究优先级（2026-11-04 本人明确）

全学科仍是项目的覆盖范围，**实际有考试的科目优先研究**。优先取得原卷、参考答案、评分细则和答题卡，逐题核对题干、材料、小问、作答位置、分值与评分点。考试类别、计分方式和科目随地区、学段与年份记录。

| 顺序 | 样本范围 |
|---|---|
| 第一批 | 小学以语文、数学、英语为主要抽样对象，按实际校内测试或质量监测资料核对。初中以语文、数学、外语、道德与法治、历史、地理、物理、化学、生物学为主。高中以语文、数学、外语和各地选考科目为主。 |
| 第二批 | 补地区实际考查的听说、理化生操作、体育、信息科技或信息技术、通用技术等，优先找能改变题目字段与评分结构的样本。 |
| 后续补充 | 以过程评价、作品或实践为主的课程先保留分类入口，具体任务随地区考试安排或后续补证纳入。 |

## 执行

1. 以教育部课程方案建立学段与学科覆盖矩阵。课程、课程版本、学段、地区、考试层级分别记录。
2. 优先找教育考试机构、教育主管部门发布的原卷、样题、答案或评分材料。记录学段、科目、地区、年份、原题定位、题目形式和材料是否齐全。学校试卷、模拟卷、评价工具另标。小学由本地原件补充。
3. 每类样本记录试卷、题组、共享材料、小题、交互、作答、评分和媒体需求。主动查阅读、实验、听力、作文、跨学科材料和表现性任务。无原题的科目保留缺口，并区分课程依据和样题证据。
4. 对比 GitHub 项目、开放交换规范和本地原型。核对官方仓库、仓库所述功能及许可入口。比较题型扩展、共享材料、媒体、评分、组卷、导入导出。代码可参考与试题可再分发分别判断。
5. 输出研究报告与证据表。将通用字段、可选扩展和需独立建模对象分开。用样本回推模型，并列出待验证事项。

## 自审及修订

- 初稿把“找齐真题”和“全学科覆盖”放在同一验收项。修订后，全科覆盖用课程矩阵验收，原题覆盖用证据矩阵验收。体育、艺术、劳动等可补正式评价任务和量规，仍按各自证据级别记录。
- 初稿按科目堆字段，容易把题型与知识点绑死。修订后按资料对象和评分机制抽取，再用跨科样本复核。
- 初稿把仓库功能说明当成软件验证。修订后区分文档、静态实现与运行结果，本轮保留前两类。
- 执行门槛已核对。研究范围、来源等级、缺口记录、输出与授权边界明确，进入资料调查。
