# 备份与恢复设计 V1

2026-11-05 · 对应 M4 / REQ-06

## 1. 目标与边界

备份把当前题库收成一个可校验、可搬运的目录包，包含数据库一致性快照、考试原卷、题目配图、组卷定稿 PDF 与版本信息；恢复先在独立位置校验，再用它替换当前题库，失败不覆盖原库。模型密钥不进入备份。

不在本版：云同步、自动定时备份、增量备份、跨设备合并。备份包可由用户复制到另一台机器后手工恢复。

## 2. 备份包结构

```
PaperWeave-backup-20261105-142530/
  manifest.json
  database/paperweave.sqlite
  attachments/<sha256>
  originals/<sha256>.pdf
  papers/<finalization-id>/student.pdf
  papers/<finalization-id>/teacher.pdf
```

- `manifest.json` 最后写入，存在即代表备份完成。
- `database/paperweave.sqlite` 由 `VACUUM INTO` 生成，是一致快照，不复制 WAL／SHM 边车文件。
- 附件、原卷、定稿 PDF 按内容校验值命名或只读保存；复制时逐个计算 SHA-256。
- 不复制 `ai-key.bin`、日志、缓存、临时目录。

`manifest.json`：

```json
{
  "format": "paperweave-backup",
  "formatVersion": 1,
  "dataVersion": 7,
  "appVersion": "1.0.0",
  "createdAt": "2026-11-05T06:25:30.000Z",
  "totalBytes": 123456,
  "files": [
    { "path": "database/paperweave.sqlite", "size": 4096, "sha256": "…" }
  ]
}
```

校验规则：`format`、`formatVersion` 必须匹配；`dataVersion` 不得高于当前应用支持版本；`files` 路径不得为绝对路径或含 `..`；每个文件存在、大小与校验值一致；清单外文件忽略。

## 3. 备份流程

1. 用户选择保存位置，确认后进入维护状态：界面显示「备份进行中，暂不可编辑」，主进程拒绝新的写操作。
2. 在目标父目录创建临时目录，完成数据库快照、文件复制、逐个校验。
3. 写入清单并原子改名成最终目录；已存在同名目录时拒绝覆盖。
4. 无论成功或失败，退出维护状态；失败清理临时目录，不留下半成品备份。

## 4. 恢复流程

1. 用户选择备份目录，界面展示清单摘要（创建时间、数据版本、文件数与总字节数），确认前不改动任何数据。
2. 在 `<userData>/.restore-staging-<id>/` 重建备份内容并逐项校验；用当前代码打开暂存库，执行迁移并检查 `PRAGMA integrity_check`，确认原卷、附件、定稿 PDF 引用文件齐全。
3. 校验失败、版本不支持或文件缺失：删除暂存目录，当前题库不变。
4. 校验通过后写入 `restore-request.json`（记录暂存目录与原库暂存目录），进入维护状态并重启应用；此时尚未改动当前题库。
5. 重启时先应用恢复请求：把当前数据移入 `.restore-previous-<id>/`，把暂存内容移入正式位置，立即打开新库并做完整性检查。成功才删除原库目录；失败则把原库移回并保留可启动状态，暂存备份丢弃，教师可重试。
6. 数据库快照前清除 `pdf.pending`、`paper.pending` 两类包含外部绝对路径的进行中操作记录；定稿 PDF 恢复后统一放到 `<userData>/papers/<id>/`，并改写数据库中的绝对路径，保证跨机器可用。

## 5. 界面

新增「备份与恢复」页：备份位置选择、备份结果摘要；恢复区展示所选备份的清单摘要与风险提示，需二次确认。备份或恢复进行中由主进程拒绝写入并在页面提示，其他页面的保存与提交会返回明确错误。

## 6. 安全

- 备份不包含 AI 密钥；恢复后密钥仍需重新配置或保留本机现有密钥（恢复只替换题库数据，不动 `ai-key.bin`）。
- 清单路径做规范化与越界检查，恢复不跟随符号链接。
- 备份包内只有应用数据，不含可执行文件；恢复只读取清单登记的文件。

## 7. 验收映射

| 验收 | 覆盖 |
|---|---|
| REQ-06 备份完整性 | 数据库快照 + 原卷 + 配图 + 定稿 PDF + 清单校验值 |
| REQ-06 恢复失败不覆盖 | 版本、校验值、缺文件、切换失败四类路径 |
| REQ-06 备份期间暂停写入 | 维护状态拒绝写操作，结束后恢复 |
| 密钥不进备份 | 备份目录扫描无密钥文件与明文 |
