## M0 数据库骨架（Issue #3，2026-11-04）

macOS arm64 打包应用实际使用 Electron 45.2.2 内置 Node 24.22.2 的 `node:sqlite`，SQLite **3.53.4**。隔离目录中验证了应用首次建库、版本 1 初始化、写入和应用重开后读取；不支持的更高版本及未识别的既有库由单元测试验证拒绝且保留原数据。`npm run check` 和打包后 `npm run test:packaged-db` 通过。Node 将此 API 标为实验性，后续 Electron 升级需重测。

当前只有设置表和初始化迁移骨架，并非题库数据模型；未来迁移、备份恢复及并发写入仍须在各自任务中验证。Windows 打包运行与驱动验证待补，不据 macOS 结果推断通过。

## M0 编辑器进展（Issue #4，2026-11-04）

编辑器采用应用内受控内容块，公式预览用 KaTeX **0.19.1**，保存公式源表达式，不存任意 HTML。支持段落中的文字片段及粗体、斜体、下划线、上下标，行内及独立公式，PNG/JPEG 图片（单张不超过 5 MiB）和纯文字基础表格（最多 30 行、10 列）。暂不支持表格合并单元格、单元格内公式、富文本或图片直接粘贴；界面提供限制提示和裁图／改写路径。

数据库格式从 1 升至 2，添加一份 M0 编辑草稿；图片存于本机附件目录，以内容指纹引用并在保存及读取时校验。当前添加但未保存、或从草稿移除的图片可能留下未引用文件，暂不自动删除；附件回收与中断恢复需后续实现和验证。该草稿不是正式题库题目，也不提供多个题目的管理。

macOS 上自动化从界面输入自制内容，检查样式预览、公式修改、图片和表格保存重开，并检查图片缺失时拒绝加载以保护草稿；同批检查断网启动和中文路径打包启动。`npm run check`、`npm run test:e2e` 和 `npm run test:packaged-db` 通过。界面操作使用与安装包同版代码的 Electron 自动化；安装包的数据库与启动另有检查，尚未对安装包内编辑流程做独立人工验收。PDF 导出一致性、纸样、用户体验和 Windows 均待验，Issue #4 不能关闭。

## M0 PDF 样张进展（Issue #5，2026-11-04）

当前仅生成**单份编辑草稿样张**：A4 纵向，四边各 20 mm，比例 100%，表格按行尽量分页，不主动缩放图片。公式为空或错误、图片未载入／超出可打印区域、过大的公式或表格行会阻止生成并提示。使用系统保存对话框选路径，PDF 写入完成后交由系统默认程序打开同一文件；打印需要在该程序中操作，尚未实测该入口或实体打印。已选定的同名文件由系统保存对话框处理覆盖确认。

macOS arm64：`npm run check` 和 `npm run test:e2e` 通过；后者通过界面输入自制中文、公式、图片和表格后生成 PDF，验证无效公式和超大图片提示。自动化中的文件对话框和打开系统程序被替身替代，因此不代表实际系统对话框、预览程序或打印机已验。用 `pdfinfo` 检查为一页 A4，以 `pdftotext` 和渲染图检查该页中文、公式、图片及表格；样张留在被忽略的 `test-results/`，重新运行测试会重建。此样张不覆盖长文、跨页表格及纸样验收。

KaTeX 资源来自应用构建，中文目前使用系统字体，尚未完成跨平台字体随包验证。学生卷与教师答案卷的数据和独立生成、双文件提交及中断恢复、实际纸样、安装包内编辑导出和 Windows 实测仍待完成；Issue #4、#5 和 M0 保持开放。

后续复核：通过 macOS「预览」直接打开上述 PDF 并进入系统打印对话框，看到 A4 纵向；当时默认“缩放以适合”显示约 97%，所以应用提示打印时选择 100%。这是对系统预览入口的检查，未实打，也未从应用实际调用默认程序验证整条链路。另用界面输入 80 行自制长文和 30 行表格，生成 4 页 A4；文本提取可见全部 80 行和 30 行表格，四页渲染图均已查看，表格在行间分页。`npx playwright test tests/e2e/pdf.spec.ts` 和 `npm run check` 通过；多页样本及渲染只说明该样本通过，不代表任意内容分页均通过。

## M0 AI 文字输入进展（Issue #6，2026-11-04）

调用链：主进程用 PDF.js（`pdfjs-dist` **6.5.438**，legacy 构建）提取逐页纯文字，渲染进程只接收文字与页码；教师勾选页面、可在文本框中修改，确认页完整展示将发送的文字、服务地址、模型与页码。固定响应用 `PAPERWEAVE_AI_FAKE` 注入，不触网；真实请求走 Anthropic 兼容的 `/v1/messages`，120 秒超时、可取消。扫描件没有文字层时明确提示改走裁图（Issue #7）或手工录入，不静默发送空内容。

密钥经 Electron `safeStorage` 加密后单独保存为 `<userData>/ai-key.bin`（权限 0600），不写数据库、界面不回显、错误信息不含密钥。E2E 检查 SQLite 与密钥文件中没有明文。备份功能尚未实现，“密钥不进备份”待备份功能完成后复验。

模型返回只接受约定 JSON 结构；未知字段、越界页码、非法结构直接拒绝。界面按纯文本渲染草稿，不执行脚本、不加载远程图片。采纳后题干与选项进入编辑区，答案只写入教师参考答案；采纳后仍可人工修改并保存。草稿卡显示原卷页码，但当前草稿格式（v2）没有来源页码字段，页码尚未持久化到题库（题库模型未建）。

验证：`npm run check` 38 项单测通过；`npm run test:e2e` 13 项通过。新增 5 项 AI E2E 覆盖：固定响应确认与采纳后人工修改、PDF 文字提取、无文字扫描件提示、脚本/远程图片标记只按纯文本显示、超时/格式错误/取消/重复提交后人工输入保留、密钥不回显且不入库。测试 PDF 为自制合成夹具，见 `tests/fixtures/README.md`。

未验：真实模型调用及南充九年级语文卷第 3–4 页样本（样本不在仓库，真实调用需当次授权与费用确认）；真实文字版试卷只经合成夹具验证；安装包内 PDF 提取与 AI 流程未独立人工验收；Windows 待补验；图像输入见 Issue #7；密钥不进备份见 Issue #9。

## M0 规模与性能目标（Issue #2，2026-11-04）

以下是先于性能测试设定的工程验收目标，不是现有使用量或实测结果。旧库盘点记有 Tiku 索引 1,463 道小题、mathVault 索引 250 题，口径和实际可迁入数量仍待核对；5,000 题的测试规模留有扩展余量，不能据此推断迁入结果。参见[本地题库资料盘点](本地题库资料盘点.md)。

| 规模或限制 | 目标值 | 实测值 / 状态 |
|---|---|---|
| 题库 | 5,000 道小题，含至少 1,000 条材料及其引用，覆盖文字、公式、图片和表格 | 待构造隔离测试库并验证 |
| 原卷 | 200 份，每份 20 页、10 MiB；另测单份 100 页、100 MiB | 待准备合成样本；不是当前原卷统计 |
| 组卷 | 单卷 50 道小题，含共享材料、公式与图片 | 待实现及验证 |
| AI 单次文字 | 最多 8,000 个 Unicode 码点；超过时保留选区，提示分批 | 已实现并单测；真实文字卷待验 |
| AI 单次裁图 | 最多 4 张，每张不超过 5 MiB，合计不超过 15 MiB；超过时保留选区，提示分批或压缩 | 限额校验已实现并单测；裁图输入待 Issue #7 |
| AI 请求超时 | 120 秒；超时保留人工草稿并允许重试 | 已实现并自动化验证（缩短超时）；120 秒真实等待未做 |

容量目标适用于隔离测试库，不代表超过该规模的数据应被拒绝。AI 限额按实际发送内容检查，禁止静默截断；真实模型能力及费用须单独核验，真实调用仍按当次授权执行。

### 测量方法与目标

在上述 macOS 机器使用安装版、同一隔离测试库、断网和本地磁盘测量，记录应用版本、系统、数据规模及后台负载。每项先预热一次，再连续测量 5 次，记录全部结果及最大值；5 次均不超过目标才记通过。冷启动每次先完全退出应用；其他操作从界面实际触发，使用同一批合成数据。任何失败、超时或资源缺失都记失败，不剔除慢次。Windows 待有设备时按同一方法另记，不用 macOS 结果代替。

| 操作 | 计时起止与样本 | 上限 | 实测值 |
|---|---|---:|---|
| 冷启动 | 启动应用至主界面可操作，打开上述规模的本地库 | 10 秒 | 待实现完整题库后测量 |
| 检索 | 提交两个筛选条件及题干关键词，至第一页结果可操作；分别记录有结果和无结果 | 2 秒 | 待实现后测量 |
| 保存 | 保存一道含中文、公式、表格及一张 2 MiB 图片的草稿，至成功反馈且重开内容完整 | 5 秒 | 待实现后测量 |
| 导出 | 从 50 小题卷开始生成至学生卷、教师卷两份 PDF 均写完且可打开；不含人工预览与打印 | 30 秒 | 待实现后测量 |
| 备份 | 从确认备份至数据库与全部附件复制、校验完成；样本包含上述 200 份原卷，记录实际总字节数 | 5 分钟 | 待实现后测量 |

保存重开和导出打开检查属于成功条件；如验证本身发生在计时结束后，应单独记录，不将检查时间计入上述上限。M3、M4 按 ACC-12 复测；不能用当前空壳或少量样题的速度替代规模实测。编辑器支持范围、A4 排版和最终模型限额仍须在对应 M0 任务中验证并固定。
