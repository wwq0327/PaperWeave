# 小学与初中原卷、题库源码对照

2026-11-04 · 第二轮研究

**同一道题至少有三个不同的单位。小问可以单独检索，抽题要带齐作答依赖，评分按证据分点。** 一道小问可能有多个空，也可能只交一张图、由多个评分点共同判定。原卷题号、答题位置、评分点和题库编号应分别记录。

## 4. 先定下来的要素和验收办法

| 层级 | 应保存 | 抽样验收 |
|---|---|---|
| 原件、试卷与分部 | 原件类型和来源、学段学科及考试信息、页码、印刷题号、分部顺序、卷首指令、默认分值、答题卡版次 | 合卷中两个 23 能各自找到原卷和答案。不同学年、不同来源的评分文件分别挂接。 |
| 题组与材料 | 有序材料、图号和角色、共享候选项、播放与选答规则、哪些小问依赖前文或前问 | 抽出江西数学 23(4) 时带齐前提。语文二选一仍只提交一篇、最多 30 分。 |
| 题、小问和作答位置 | 题目稳定编号及版本、设问和限制、作答形式、顺序、数量、单位、图或选项引用。答题卡区域有证据时单独映射 | 化学 18(2) 能还原成方程式加一个装置选择。地理原图裁切仍保留图例和方向。 |
| 答案与评分 | 参考答案、可接受变体、排序或互换规则、评分点、档位、步骤分、默认分及例外、扣分和来源。解析另存 | 物理指定两空互换仍可判。小学数学作一张图可按两个评分点给分。缺档位换算或分步细则时显式标待补。 |

本轮为题号、材料依赖、答案和评分的人工对照。开发前最值得补证的是同一场考试的独立空白答题卡与评分细则，以及一份可播放的英语原始音频，用来验证“试题位置、作答位置、评分位置”三者的映射。现阶段可先用本文样本检验字段，保留学生卷重排和自动判分的实现验收。
